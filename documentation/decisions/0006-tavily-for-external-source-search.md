# 0006: Use Tavily Behind SourceSearcher for External Source Search

- **Status:** Accepted
- **Date:** 2026-11-26

## Decision

Griffier calls **Tavily's REST API** (`POST https://api.tavily.com/search`) via `httpx` inside a `TavilySearcher` adapter implementing the `SourceSearcher` protocol ([0004](./0004-provider-agnostic-protocol-boundaries.md)). Python executes search queries generated by the LLM concurrently and attaches the returned `ExternalSource` objects directly; the LLM may summarize retrieved snippets by ID, but never constructs or copies URLs.

## Why

Journalists need verifiable, real-world sources with zero risk of hallucinated links. The choice for Tavily behind `SourceSearcher` came from four practical reasons:

- **No hallucinated URLs by construction:** Because Python calls Tavily directly and passes the real URLs straight to the Intelligence panel, the LLM never has the opportunity to invent or alter a link.
- **Search and extraction in one call:** Tavily returns real URLs, titles, and clean extracted snippets ready for grounding, removing the need for a separate web-scraping layer.
- **News and domain controls:** Built-in `topic="news"` filtering and domain include/exclude options fit journalistic fact-checking well.
- **Fast, predictable, and swappable:** Running `asyncio.gather` over a ~25-line `httpx` adapter avoids multi-turn agent tool loops (working reliably even on fast models like `deepseek-flash`), and Tavily's 1,000-credit monthly free tier covers development and demos.

## Alternatives Considered

- **Tavily via MCP (`MCPServerStreamableHTTP`):** Rejected because routing search through an LLM tool loop passes raw URLs through model text (weakening deterministic grounding), adds extra tool schemas and round-trips, and still requires per-server auth/transport adjustments when swapping providers — whereas `SourceSearcher` already isolates the provider cleanly in ~25 lines of Python.
- **Exa:** Strong semantic search for policy reports and deep background articles, but pricier (~$7+/1k requests) and slower on straightforward factual lookups.
- **Brave Search API:** Cheap independent index (~$4–$5/1k requests), but returns short snippets only and requires a separate scraping layer.
- **Perplexity Search API:** Returns pre-synthesized answers with citations, blurring the boundary between raw retrieved sources and Griffier's own fact-check layer.

## Trade-offs

- **Additional API key (`TAVILY_API_KEY`):** Loaded from environment variables; automated tests inject a fake `SourceSearcher` so tests never hit live search APIs.
- **Occasional extraction noise:** Boilerplate from certain sites can appear in snippets; keeping Tavily behind `SourceSearcher` allows swapping to Exa or Brave later without touching downstream code.
